# ziv 配置交互设计（v2，2026-11-07）

> 目标：把「改一个配置」变成零歧义动作。用户原话：「我要的是一个简洁好用的功能。
> 不是我要改 a 保存不了。改 b 的时候到处乱跳。」

## 0. 现状问题（pty 复现取证，2026-11-07）

| # | 问题 | 复现证据 | 根因 |
|---|---|---|---|
| D1 | **回车假死**——按 Enter 没反应，再敲任意键才整段推进 | pty：输入 key+回车后 `Base URL` 提示 5s 不出现，进程阻塞 | `menu.readLine` 收 `\r` 后 `peekGreedy(1)` 窥望配对 `\n`——阻塞到下一字节；raw TTY 的 Enter 是单发 `\r`，永远等不到 |
| D2 | **提示撒谎**——Base URL 写「回车=官方」，实际什么都不改 | 代码 `url.len == 0` 分支不写 settings，旧 URL 原样保留；按提示操作的用户以为恢复了官方 | 文案与行为脱节 |
| D3 | **保存后乱跳**——保存完突然弹「选一个作为当前模型？」，可能再弹「让它走刚配置的接入吗？」 | `offerGatewayModels` 保存后自动网络 fetch（秒级延迟）+ 连环 `menu.select` | 配置动作混入发现动作 |
| D4 | **盲配置**——Key/URL/Brave/Ollama 提示不显示当前值、无「保留」语义 | 提示文案本身 | 未设计 |

## 1. 设计原则（四条，全部可检验）

- **P1 一条规则走天下**：所有值输入 = `回车=保留当前 · -=清除 · 输入新值=修改`
- **P2 回车立即生效**——绝不等待下一个按键
- **P3 配置动作的终点是「✓ 已保存」**——无网络往返、无连环菜单
- **P4 提示显示当前值**——改什么、保留什么，一眼可见

## 2. 交互设计

### 2.1 接入编辑（OpenAI / Anthropic）——两字段、一次保存

菜单层不变（当前值始终可见）：

```
=== 模型接入配置 ===
  ❯ OpenAI 接入（Key + 网关地址）: sk-tes.456
    Anthropic 接入（Key + 网关地址）: (未配置)
    Brave Key（网络搜索）: (未配置)
    Ollama Host（本地模型）: http://localhost:11434
    返回
```

选中 OpenAI/Anthropic 接入后：

```
  OpenAI 接入（回车=保留 · -=清除 · 输入=修改）
  API Key（当前 sk-tes.456）: █
  Base URL（当前 https://gw.example.com/v1，-=恢复官方）: █
  ✓ 已保存  Key: sk-tes.456 · Base URL: https://gw.example.com/v1
```

规则表（唯一规则，与 P1 对应）：

| 输入 | Key 字段 | Base URL 字段 |
|---|---|---|
| 直接回车 | 保留现有 key | 保留现有 URL |
| `-` 回车 | 清除 key（→ 未配置） | 恢复官方地址 |
| 输入新值回车 | 保存新 key | 保存新 URL |
| Esc / Ctrl-C | 取消整个编辑，返回子菜单 | 同左 |

两字段都直接回车 → 打印「未更改」，不落盘。

### 2.2 保存后的输出（不弹任何菜单）

1. 一行汇总：`✓ 已保存  Key: <掩码> · Base URL: <终值|官方默认>`
2. 需要选模型 → 一行提示：`（/model 可查看/切换模型）`——发现是用户主动行为
3. 路由提示（罕见：当前模型名按前缀路由到 Ollama，而刚配的是 openai/claude）
   → 一行文字：`提示：当前模型 X 按名称走 Ollama；要走此接入请用 /model 重选`
   ——原来是弹菜单，删。

### 2.3 Brave / Ollama——同一规则

```
  Brave Key（当前 sk-br.ave，回车=保留 · -=清除）: █
  Ollama Host（当前 http://localhost:11434，回车=保留）: █
```

Ollama 保存后同样只提示 `/model`，不自动拉列表。

### 2.4 `/model` picker 增加一项（网关发现的新唯一入口）

```
  自定义…（输入模型名，兼容网关可用）
  从网关列出模型（需已配 Key/Base URL）   ← 新增
  取消 (q)
```

拉取失败必须报错一行（原来静默 return，用户不知道为什么没反应）。

### 2.5 readLine 底座修复（D1 根因）

CR 后仅当**字节已在缓冲**时窥望配对 LF（粘贴/管道场景字节成对到达）；
TTY 单发 `\r` 立即结束行。P2 由这条保证。

## 3. 改动清单

| 文件 | 函数 | 改动 |
|---|---|---|
| `util/menu.zig` | `readLine` | CR 后窥 LF 加 `bufferedLen() > 0` 守卫 |

## 4. 验收标准（可判定）

1. pty：key 输入回车后 ≤2s 出现 `Base URL` 提示（D1，修复前 5s 超时阻塞）
2. pty：Base URL 空回车后 settings.json 旧 URL 原样保留（D2：文案=行为）
3. pty：保存后输出 `✓ 已保存` 且**不出现**「选一个作为当前模型」（D3）
4. pty：URL 输 `-` 后 settings.json 该字段清除（D2 反向）
5. 单测：readLine 对孤 CR 立即返回
6. pty：`/model` 菜单含「从网关列出模型」项
7. 全量单测绿 + pty 套件 12/12 全绿（S6 扩展覆盖 1-4、6）
